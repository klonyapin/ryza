```

src/ryza/press/flash.py        -- 速報エンジン(トリガー→軽量判定→執筆→短縮リンター→outbox urgent)+ predictions 登録・期限到来時の的中判定

```

## 要点(設計から必ず守る)

- リンター規則は 30-press §4 の表のとおり。U字判定: min∈{1,2}・min初出より前が非増加・後が非減少・先頭≥3・末尾=5。**L-7: 全トピックに trade_implication(action/対象/条件)必須**
- 玲音の口調(personas/press-lain/voice.md)は執筆プロンプトに注入。U字構造は人格より優先
- 速報②(予兆)は「予測」ラベル+確度+検証期限を必須とし press.predictions へ。期限到来時の的中判定ジョブも実装
- NAV 等の数値はファンド会計部の確定値のみ(provisional は「暫定」明記)
- LLM 呼び出しは全て StructuredLLM 経由(部門タグ press・コスト記録)。リンター失敗原文も研究素材として保存
- T-011 の flash_triggers(market_view の magnitude 閾値イベント)を速報のトリガー源の一つとして接続
