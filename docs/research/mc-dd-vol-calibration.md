# DD 上限 ↔ ボラ予算 ↔ 期待リターンのモンテカルロ較正

- 実施: 2026-08-03(IPS v1.2 §3.1 の根拠)/ 再較正: 実績リターン分布が貯まり次第、GBM 仮定を実分布ブートストラップに置換(研究本部)
- 手法: GBM 日次(252日・2万パス・seed 7)。E[R] ≈ SR × σ の関係の下で、年率ボラ σ ごとの年内最大ドローダウン分布を計測
- 限界: GBM はファットテール・ボラクラスタを持たないため **DD を過小評価しがち**(実運用ではブリーチ確率は表より高いと想定すべき)。ジャンプ・t分布・実分布ブートストラップでの再較正が改善課題

## IPS への含意

1. DD25% 上限の下で(ブリーチ確率 ≤10%)、σ予算は 15〜20%。SR 1.0 仮説なら目標リターンは**年率 16〜22%**が整合値
2. **年率 100% は DD25% と両立しない**: SR 1.0 では σ≈70% が必要でブリーチ確率 98%。SR 2.0(世界最高水準)でも σ50% でブリーチ確率 60%
3. 参照実績: Medallion 年率約66%(グロス、手数料後約39%、レバ約8〜20倍・超高頻度)/ ドラッケンミラー約30%/年(30年)/ 大手マルチストラット 15〜25%(ポッド DD カット 5%前後)。**年率100%超の持続実績は公開記録に存在しない**
4. 高リスク追求は moonshot 実験プロファイル(DD60%・σ50%)で行い、SR 仮説の実現可能性自体をデータで検証する

## 再現コード

```python
import numpy as np
rng = np.random.default_rng(7)
days, sims = 252, 20000
for sr in [0.5, 1.0, 1.5, 2.0]:
    for vol in [0.10, 0.15, 0.20, 0.30, 0.50, 0.70, 1.00]:
        mu = sr * vol
        r = rng.normal(mu/days, vol/np.sqrt(days), (sims, days))
        eq = np.cumprod(1 + r, axis=1)
        dd = 1 - eq / np.maximum.accumulate(eq, axis=1)
        mdd = dd.max(axis=1)
        print(sr, vol, eq[:, -1].mean()-1, np.median(mdd), np.percentile(mdd, 95), (mdd > 0.25).mean())
```
