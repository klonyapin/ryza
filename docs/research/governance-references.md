# ガバナンス制度の参照調査 — 定款・権限マトリクス・実装監査の設計根拠

- 作成: 2026-08-03(調査: 3並列エージェント、全 URL フェッチ確認済み)/ 用途: `06-constitution.md`・`config/governance.yaml`・監査 A-18 の設計根拠
- 経緯: 2026-08-03 決議([議事録](../minutes/2026-08-03-governance-constitution.md))。代表指示「日本や金融庁のガイドラインや実際の会社等を参考に」

Ryza の定款体系は、監査等委員会設置会社型の「定款授権による大幅委任」を骨格に、金融庁監督指針の態勢整備要件と J-SOX の統制マトリクス様式を執行可能な形で移植するのが最適である。以下、制度ごとに要点と転用方針を示す。

## 1. 会社法 — 定款の構成と機関設計

- 定款の記載事項は3類型: 絶対的(27条: 目的・商号・所在地・出資額・発起人)、相対的(定めなければ効力を生じない事項 — 機関設置を含む)、任意的(29条)。[e-Gov 会社法](https://laws.e-gov.go.jp/law/417AC0000000086)
- 機関設計3型の核心は**業務執行決定の委任可能範囲**: 監査役会設置会社は重要業務執行を委任不可(362条4項)、監査等委員会設置会社は定款の定めで大幅委任可(399条の13第6項)、指名委員会等設置会社は執行役へ原則委任(416条4項)
- **転用**: Ryza は「代表(ユーザー)が定款で システム(執行側)に広範な執行を授権し、専決事項のみ留保する」構造 = 監査等委員会設置会社型のアナロジーを採る。専決事項の明示列挙が定款の中核になる
- 規程階層の実務標準: 定款 → 経営基本規程(取締役会決議)→ 組織・職務権限・稟議規程 → 細則・要領(下位ほど決裁権限を下げ機動性を確保: 規程=取締役会/要領=代表/基準=管掌役員)。[EY 解説](https://www.ey.com/ja_jp/technical/library/info-sensor/2017/info-sensor-2017-10-05)、[規程管理実務](https://michibiku.co.jp/media/article/6mjdq33s6/)
- 制定・改廃フローの標準形: 起案 → 関係部門審査 → 決裁 → 公布 → 周知 → 定期見直し。施行日は附則に明記。版管理・原本保管は主管部門が担う

## 2. 金融庁 — 態勢整備・三つの防衛線・内部監査成熟度

- [金商業者向け総合監督指針](https://www.fsa.go.jp/common/law/guide/kinyushohin/index.html): III 章(経営管理=代表の率先垂範と取締役会の達成度検証/コンプラ部門の独立性/リスク管理方針の明確化と定期報告/内部監査の独立・包括・遅滞ない報告)、VI 章(投資運用業: 運用部門の独立、**投資判断部門と発注部門の分離**(小規模は担当者分離)、利益相反管理、外部委託モニタリング)
- **転用**: 「投資判断と発注の分離」は監督指針の明文要求であり、Ryza 不変原則1(LLM は判断材料、発注は決定論コード)の外部制度上の根拠になる。定款に引用する
- [コンプライアンス・リスク管理基本方針](https://www.fsa.go.jp/news/30/dp/compliance_revised.pdf)(2018): 三つの防衛線(1線=事業部門の自律統制/2線=コンプラ・リスク部門/3線=内部監査)+リスクベース・アプローチ+「形式から実質・カルチャーへ」。形式的導入自体を目的化しない留保付き
- [内部監査の高度化](https://www.fsa.go.jp/news/30/naibukannsa_report5.pdf)(2019): 成熟度4段階 — Ver.1.0 事務不備監査 → Ver.2.0 リスクベース監査 → Ver.3.0 経営監査(ガバナンス・リスク管理・統制の有効性評価、取締役会直接報告)→ Ver.4.0 信頼されるアドバイザー。転換軸は「過去→未来・形式→実質・部分→全体」
- **転用**: Ryza 監査部門の目標水準を Ver.3.0(経営監査)と定款に明記。A-18(規則⇔実装トレーサビリティ)は Ver.2.0〜3.0 の実装形

## 3. 実在組織 — GPIF・投資運用業者

- GPIF: 2017 年法改正で経営委員会(意思決定・監督)と執行部(理事長)の**二層分離**。文書体系は中期目標→中期計画→年度計画+投資原則・管理運用方針。[GPIF 経営委員会](https://www.gpif.go.jp/about/board.html)
- 投資運用業の登録3本柱: 業務方法書・人的構成・内部管理態勢([金融庁ガイドブック](https://www.fsa.go.jp/policy/marketentry/guidebook/index.html))。法定根拠は業務管理体制(金商法35条の3)・利益相反管理(36条)・最良執行(40条の2)
- 自主規制は旧・投資顧問業協会が**資産運用業協会(imaj.or.jp)へ統合済み**: 「業務執行体制に関する自主規制基準」等。[規則一覧](https://www.imaj.or.jp/about/information/rules.html)
- フロント(運用)/ミドル(リスク)/バック(計理)の三分離が業界標準形。「組織規程・職務権限規程・文書管理規程」の標準セット名は一次資料で確認できず実務慣行として扱う

## 4. J-SOX — 統制マトリクス(RCM)の様式

- [実施基準](https://www.fsa.go.jp/news/r4/sonota/20230407/1.pdf)(2023 改訂・2024 適用)の「参考3: リスクと統制の対応(例)」の公式列構成: **業務/リスクの内容/統制の内容/要件(アサーション)/評価/評価内容**。3点セット(流れ図・業務記述書・RCM)は**法定様式ではなく参考例**と明記。「統制の種類(予防・発見)」「評価手続」列は実務上の拡張
- **転用**: `config/governance.yaml` の統制テーブルは「規則(条文参照)/リスク/執行点(スキーマ・ゲート・CI・監査ジョブ)/種別(予防・発見)/検証手続(A-18 が実行)」の5列で設計する。公式様式の最小主義に倣い列を増やしすぎない

## 設計への含意(まとめ)

1. 定款は「専決事項の列挙+広範な執行授権」型(監査等委員会設置会社アナロジー)で薄く書ける
2. 文書4層(定款>IPS・基本規程>マンデート・実施規程>手順・設定)に改訂権限を対応付けるのは日本の規程管理実務の標準形そのもの
3. 全条文への執行点紐付けは J-SOX RCM の直接応用であり、A-18 は「RCM の評価手続列を自動実行する監査ジョブ」と定義できる
4. 監査部門の目標水準は金融庁成熟度モデル Ver.3.0(経営監査)
