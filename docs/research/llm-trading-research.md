# 調査: LLM/マルチエージェント取引システムの研究知見(2026-08-02 時点)

設計根拠資料。2024〜2026年の論文・OSS・実弾実験の調査結果。

## 主要システム

| システム | 構成 | 報告結果 | 検証で判明した限界 |

| TradingAgents (arXiv 2412.20138) | アナリスト群→強気弱気討論→トレーダー→リスク→承認の階層 | ベースライン超と報告 | 著者自ら非決定性を明記。コスト込み再現で Sharpe 0.43→0.22、buy-and-hold 以下 |

## 決定的な批判研究

### The Alpha Illusion (arXiv 2605.16895)
主要 LLM 取引エージェントを横断検証:
- 汚染統制(学習カットオフ後評価)で FinMem -71.85%、QuantAgent Sharpe -51%
- 手数料・スプレッド・**トークンコスト込み**で主要エージェントが buy-and-hold 以下
- 短期間評価の Sharpe は95%信頼区間が広すぎて差が統計的に区別不能
- LLM 確信度はキャリブレーション不良(ECE 未測定)→ サイズに直結させるのは危険
- 反対証拠60%でも意見反転率約8% → LLM は事前分布(テック贔屓等)に固執
- 提案プロトコル P1〜P6: カットオフ後評価/動的ユニバース/反証拠ロバスト性/キャリブレーション/実装コスト込み/単一エージェント対照

### ルックアヘッド(学習データ汚染)
- GPT-4o は学習期間内の S&P500 終値を誤差1%未満で「想起」できる → 期間内バックテストは予測でなく記憶の再生
- LAP 測定(arXiv 2512.23847): 汚染度は学習期間内で一貫して正、カットオフ直後にゼロへ崩落
- 実用対策: **カットオフ後データのみで評価 + ペーパートレードでの前向き検証**

### StockBench (arXiv 2510.02209)
カットオフ後・汚染フリーで14モデル評価: トップモデルはベースライン超もあるが「大半の LLM エージェントは等配分 buy-and-hold に勝てない」「金融QAベンチのスコアは取引成績を予測しない」「弱気相場でベースレイン割れ」

### センチメント
- Lopez-Lira & Tang (arXiv 2304.07619): カットオフ後ヘッドラインで GPT-4 センチメントが翌日リターンを有意に予測。ただし効果は小型株・短期・悪材料に集中し、コストで縮む
- 含意: 「センチメントを LLM に読ませる」ことと「LLM に取引させる」ことは別問題

### 実務の定説
- ヘッジファンド実務(Balyasny、Bridgewater 事例): LLM 用途は文献統合・要約・コード生成。LLM 出力自体を検証対象として扱い、発注判断に直結させていない
- 学術・実務の収束点: LLM は上流(スキーマ制約付き情報抽出)、特徴量構築→シグナル合成→キャリブレーション→サイジング→執行は決定論的モジュール。「最終決定権を LLM から外すことで健全性が構成的に担保される」

## 設計に効く教訓(採用済み)

1. バックテストは必ずモデルの学習カットオフ後の期間で行う
2. LLM は情報抽出・要約・仮説生成まで。サイジング・リスク・執行は決定論的コード
3. LLM の確信度をそのままポジションサイズにしない(独立のキャリブレーションモジュール)
4. 常に等配分 buy-and-hold を対照に、全コスト(手数料・スリッページ・トークン)込みで評価
5. 短期間 Sharpe で意思決定しない(複数レジーム+複数シードで分散を報告)
6. 非決定性は設計で扱う(LLM 出力を離散シグナル+根拠スキーマに落とし下流を決定論化)
7. マルチエージェント化は単一エージェント対照で効果検証してから
8. 反証拠での「意見反転テスト」をエージェント評価に組み込む
9. 自己改善ループの対象は「LLM の取引判断」でなく「戦略コード/特徴量」(QuantAgent 型。バックテストが自動評価者)
10. センチメントはスコア化(LLM)→シグナル合成(決定論)と分離して使う
