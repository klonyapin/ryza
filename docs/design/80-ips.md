# Ryza 投資方針書(IPS)v1.0 ドラフト

- ステータス: **投資委員会の最終確認待ち**(骨格4項目は 2026-08-02 に決定済み、残余は設計リードが整合案として起案)
- 骨格: CFA Institute 機関投資家向け IPS 標準構成+GPIF 型政策ミックス
- 確定後: 機械可読版 `config/ips.yaml` を生成し、コンプライアンス・リスク両エンジンはそれのみを参照する
- 変更手続: ユーザーのみ起票可。全変更は版管理+承認記録

## 1. 範囲と目的

- 投資家: ユーザー個人(自己資金・自己運用)
- 対象: Ryza が管理する全帳簿(当面 DEMO_FUND のみ。基準通貨 JPY、初期出資金 ¥1,000,000)
- 目的: 自己資金の長期成長と、自己進化型運用システムの検証・学習の両立。デモ期間中も本 IPS を実弾と同じ規律で適用し、規律遵守の実績自体を実弾移行の判断材料とする

## 2. ガバナンス

- 投資委員会(ユーザー): 本書・政策ウェイト・戦略昇格・システム変更の承認。緊急停止権限
- システム(Ryza): 政策ウェイトの乖離許容幅内での運用裁量

### 2.1 IPS 改訂フロー

原則: **発効の決定権は常にユーザー。ただし見直しの契機・批判はシステム側からも出す。**

1. **四半期定期レビュー**: CIO ペルソナ(05-governance.md — セッションに依存しない役職資産として永続化された AI 役員)が「IPS 批判レポート」を起草し、独立役員ペルソナの意見書を添えて、投資委員会(役員室 Web UI)で代表と対話して改訂を検討する。レポートの必須内容:
   - 遵守実績(ゲート却下・リミット超過の統計)
   - 制約がバインドした箇所(「この制約がなければ何をしていたか」の機会費用分析)
   - IPS 自体への批判(矛盾・実務との無理・形骸化した条項の指摘)
2. **臨時見直し提案**: 次のトリガーで Fable・リスク管理部・監査部門は随時「見直し提案」を起こせる(発効はユーザー確定のみ):
   - DD ソフトリミット(15%)到達 / 監査 critical 指摘 / ストレステストのエスカレーション / 市場レジームの構造変化
3. **確定手続**: 対話 → 改訂案(diff 明示)→ ユーザー確定 → 版番号+効力発生日を記録 → `config/ips.yaml` 再生成 → エンジンが新版参照。旧版は履歴保持
4. 頻繁な変更の抑制: 定期レビュー以外の改訂は原則トリガー事由がある場合のみ。改訂履歴自体も四半期レビューの評価対象(「ルールを曲げた回数」を可視化)

## 3. リターン・リスク目標

| 項目 | 値 | 備考 |
|---|---|---|
| 目標リターン | 年率 10%(コスト控除後) | 積極プロファイルに整合 |
| **最大ドローダウン許容** | **25%**(確定) | サーキットブレーカー発動点 |
| DD 15% 到達時 | 警告+新規建て枠を半減(ソフトリミット) | 段階的ディフェンス |

| ベンチマーク | ①政策ミックス複製(指数連動)②等配分 buy-and-hold | ②は評価プロトコル E3 と整合 |

## 4. 政策ポートフォリオ(株式中心バランス型・GPIF 型2階建て)

| 資産クラス | 目標 | 乖離許容幅 |
|---|---|---|
| 国内株式 | 30% | ±8% |
| 外国株式 | 30% | ±8% |
| 債券 | 15% | ±6% |
| 戦術枠(FX・暗号資産・コモディティ先物) | 10% | ±5%(うち暗号資産は NAV の 5% 以内) |
| 現金 | 15% | ±10% |

- 2階目(大分類): 株式合計 60% ±10% / リスク資産合計(現金・債券以外)±12%
- リバランス: 許容幅超過時に自動で注文案生成 → 通常フロー(ゲート経由)で執行

## 5. 制約・禁止事項

| 項目 | 値 |
|---|---|
| **レバレッジ上限(グロス/NAV)** | **2.0x**(確定)。維持率はブローカー要求+バッファ 20% を下回ったら新規建てブロック |
| **1銘柄集中度上限** | **NAV の 20%**(確定)。発行体単位で合算 |
| 1日の売買代金上限(暴走ガード) | NAV の 30% |
| 最低保有期間 | 1営業日(過剰取引・コスト支配の防止) |
| 禁止対象 | レバレッジ型・インバース型 ETF / 監理・整理銘柄 / 制限銘柄リスト(config で管理)。レバ型 ETF 禁止の理由: ①日次リバランス構造によるボラティリティ・ドラッグで長期保有では原指数の N 倍にならず減価する ②帳簿上1単位でも実効エクスポージャーが N 倍のため、レバレッジ上限 2.0x やデルタ調整集計の計算を狂わせる「見えないレバレッジ」になる。同じ積極性は信用・先物の「測れるレバレッジ」(2.0x 枠)で取る |
| ショート | 許可(レバレッジ・集中度の制約内。個別銘柄ショートは1銘柄 NAV の 10% まで) |

## 6. モニタリング・報告・エスカレーション

- 日次: リスクレポート・NAV(Discord)/ 常時: リミット監視・超過即時アラート
- 月次: パフォーマンス・予実差異・ストレステスト・監査報告
- エスカレーション: ストレステスト想定損失が NAV の 20% 超 → 委員会へ即時通知と対応協議

## 7. 既知の論点(Fable 指摘・次回レビューで判断)

1. **集中度20% × 日本株の単元制約の衝突**: 日本株は100株単位のため、NAV ¥100万では株価2,000円超の銘柄が1単元で20%を超える。単元未満株はデモ環境(IBKR ペーパー)非対応。選択肢: (a) 日本株は当面 ETF 中心+個別は低位株のみ (b) 日本個別株に限り集中度の実務例外を設ける (c) NAV 増額まで日本個別株を戦術枠扱いにする
2. NAV ¥100万に対する目標リターン10%(年 ¥10万)と運営実費(LLM 費等)の比率: E4 のコスト込み評価ではデモ NAV 規模だと費用が支配的になる。評価時は「NAV 1,000万円換算の配賦」等のスケーリング規約が必要になる可能性
