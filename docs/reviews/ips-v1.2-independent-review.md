## 1. 総合判定: 条件付き承認

本 IPS は骨格(二層構造・リスク上限の金融工学的導出・決定論的執行経路・Kill Switch 多段化)において機関投資家水準の設計思想を持つが、**中核である §3.1 の運用値が自らの設定条件(ブリーチ確率 ≤10%)を実質的に満たしていない疑いが強く、かつ σ予算に執行機構が存在しない**。この2点は `config/ips.yaml` 生成後にエンジンの挙動として固定化されるため、承認前の解消を条件とする。

**承認の前提条件(config/ips.yaml 生成前に必須)**:

1. **DD の測定定義を明文化する**(測定起点=設定来ピークか年次リセットか、対象=帳簿別か合算か)。設定来ピーク基準を採る場合、§3.1 の較正を複数年ホライズンで再実行し、σ予算を再設定する(下記 懸念1)
2. **σ予算の執行機構を定義する**(実現/予測ボラの監視主体・測定方法・超過時のアクション)。現状の日次 ES 3% 上限は年率ボラ約23%相当であり、15〜20% の σ予算を執行しない(懸念2)
3. **単元例外に上限を付す**(例: 1単元の取得価額が NAV の一定割合を超える銘柄は例外対象外、または例外ポジションの信用買い禁止)(懸念3)
4. **政策ミックス廃止の残骸を除去する**: 付録「株式中心バランス型」・§3.2 ベンチマーク①・00-system-design §9「GPIF 型2階建て乖離幅」の3箇所を §4 の新方針と整合させる(懸念4)
5. 81-fm-mandates.md のマンデート表に**ポッド別 σ配分とポッド別レバレッジ上限**を追加する(IPS §4.1 が要求する構成要素がマンデート表に存在しない)(懸念2・整合性 C-5)

**承認後のフォローアップ条件(初回月次レビューまで)**:

6. 実績 SR の月次更新に推定誤差の下限措置(最低サンプル期間・縮小推定)を導入する(懸念5)
7. §8 に挙げる CFA 標準要素の欠落(通貨ヘッジ方針・税制・時間軸・資産クラス分類定義)を補完する。**実弾移行時には税制条項なしでの移行を不可とする**

差し戻しとしなかった理由: 指摘事項はいずれも修正方法が明確で設計骨格の変更を要さず、また現段階はデモ運用のみで実資金への即時の危険がない。ただし条件1・2が未解消のまま yaml が生成された場合、本意見書は差し戻し相当に格上げされるべきである。

## 2. 重大懸念(深刻度順)

### 懸念1(最重大): DD 較正のホライズン不整合 — 「ブリーチ確率 ≤10%」は測定定義次第で虚偽になる

**何が問題か**: §3.1 の較正(mc-dd-vol-calibration.md)は「**年内**(252日)最大ドローダウン」を測定している。一方、IPS §3.2 の DD 25% ハードリミットには測定ウィンドウの定義がなく、サーキットブレーカーの性質上、実装は自然に「設定来ピークからの下落」(リセットなし・連続測定)になる。この2つは別物である。当職の追試では、SR 1.0・σ20% の同一 GBM 仮定下で、連続測定 P(DD>25%) は **1年 8.1% → 3年 約33%**(4,000パス)。つまり文書が「ブリーチ確率 8.2%」と提示する運用値は、3年運用すれば3回に1回サーキットブレーカーに到達する水準である。さらに較正文書自身が認める GBM の DD 過小評価(ファットテール・ボラクラスタ欠如)がこれに上乗せされる。σ20% の 8.2% は基準の 10% に対し 1.8pp しか余裕がなく、既知の下方バイアスを持つ推定値に対する安全域として不十分である。

**放置した場合**: (a) ユーザーは「ブリーチはおよそ10年に1度以下」という誤った期待でリスク上限に合意することになり、インフォームド・コンセントが成立しない。(b) 数年内に高確率で全新規発注停止に入り、復帰判断のたびに「上限を緩める」圧力が生じる — §2.1 が警戒する「ルールを曲げた回数」の常態化経路そのもの。

**修正案**: ①DD 定義(起点・リセット規則・対象帳簿)を §3.2 に明記。②較正を運用想定ホライズン(最低3年)の連続測定で再実行し、その定義でブリーチ確率 ≤10% を満たす σ予算を再設定する(概算では σ12〜15% 程度まで下がる可能性があり、目標リターン帯も機械的に下方修正される — それがこの導出規約の正しい帰結である)。③GBM バイアス分の明示的ヘアカット(例: 較正確率に係数を掛ける、または実分布再較正まで σ予算上限を暫定 15% とする)。

### 懸念2: σ予算に執行機構がない — リスク予算が「飾り」になっている

**何が問題か**: §3.1 は σ予算(15〜20%)から目標リターンを導出し、§4.1 は「ファンドの σ予算をマンデートで各ポッドへ配分」すると定めるが、(a) 81-fm-mandates.md のマンデート表には σ配分の行が**存在しない**(資本・ポッド DD・集中度のみ)、(b) IPS のどこにも実現/予測ボラティリティを監視し超過時に介入する規定がない。ボラに最も近い拘束は日次 ES(95%)3% だが、これは正規近似で年率ボラ約 **23%** に相当し、σ予算 15〜20% より緩い。つまりファンドは σ予算を超えて走ることができ、止まるのは DD が実現した後である。目標リターン導出の前提(σ=予算値)と実際に許容されるリスク水準が切断されている。

**放置した場合**: 実現ボラが予算を超過しても何も起きず、§3.1 の「E[R] ≈ SR × σ」導出全体が事後的に無意味化する。DD ブリーチ確率も較正の前提(σ=15〜20%)より高い水準で実現する(懸念1を悪化させる)。

**修正案**: ①§3.2 の表に「実現ボラ(例: EWMA 20日年率換算)が σ予算 +α を超過したら新規建てブロック」の行を追加。②マンデート表にポッド別 σ配分とポッド別グロスレバレッジ上限を追加(現状、ポッド単位のレバ上限は存在せず、先物・FX を扱う Stan のポッドはファンド全体 2.0x の範囲内で事実上無制限のポッド内レバを張れる)。③相関を考慮した合算 σ の監視責務(中央リスク管理部)を §3 に明記。

### 懸念3: 単元例外が集中度上限を実質無効化しうる(上限なしの例外)

**何が問題か**: §7.1 は日本個別株について「1単元までは集中度 20% の超過を許容」とし、例外に**金額上限がない**。東証には1単元(100株)の取得価額が数百万円に達する値がさ株が実在するため、NAV ¥10,000,000 の本帳簿でも1単元で NAV の 30〜50% に達する銘柄を取得でき、E8 の小規模帳簿(¥10万〜100万)では1単元が NAV の 100% を超える銘柄すら例外の文言上は許容される(信用 2.0x 枠と併用すれば執行可能)。「少額投資家の現実を写す」という趣旨は正当だが、現実の少額投資家は資金制約で自然に値がさ株を回避するのに対し、ゲートの例外条項は明示的に上限を書かない限りその歯止めを持たない。

**放置した場合**: 単一銘柄イベント(決算ショック・不祥事)で帳簿が一撃で DD ソフト/ハードリミットを踏み抜く。集中度上限 20% が守るはずだった毀損経路が、例外条項経由で復活する。

**修正案**: 例外に上限を付す — 例:「1単元の取得価額が NAV の 35% 以下の銘柄に限り例外適用。かつ例外適用ポジションの信用買いは不可」。あるいは値がさ株は単元未満株(ミニ株)対応ブローカーでの執行に限定するか、実行可能ユニバースから除外し「その規模では買えない」ことを E8 の情報として扱う(§7.2 の思想と整合する)。

### 懸念4: 政策ミックス廃止(§4)の残骸が3文書に残り、機械可読化で矛盾が固定化する

**何が問題か**: §4 は政策ミックスを廃止し「運用をこれに寄せる義務はない」としたが、(a) 80-ips.md 付録の確定済み決定に「**株式中心バランス型**」が残存(FM 裁量の §4 と矛盾。この文言が確定事項なら §4 が違反、そうでないなら付録が誤り)、(b) §3.2 ベンチマーク①「政策ミックス複製(指数連動)」は廃止済み概念を定義なしで参照、(c) 00-system-design.md §9 のリスクエンジン仕様に「**GPIF 型2階建て乖離幅**」が残存 — 乖離幅は目標ウェイトの存在を前提とする機構であり、目標ウェイトなき v1.2 下では監視対象が存在しない。

**放置した場合**: `config/ips.yaml` とリスクエンジン実装が「存在しない政策ミックスからの乖離」を監視するか、実装者が独自解釈で埋める。保護領域(コンプライアンスゲート)の仕様が文書間で非決定になる。

**修正案**: 付録の当該文言を「(v1.2 で §4 に置換)」と履歴化し、§3.2 ①を「参照ミックス(§4.3 の評価専用)」と書き換え、00-system-design §9 の乖離幅監視をガードレール監視(§4.2)に差し替える改訂を v1.2 確定と同時に行う。

### 懸念5: 「ハードリミット(確定)」と実験プロファイルの関係、および合算適用範囲が曖昧

**何が問題か**: §3.2 は DD25%・レバ 2.0x を「確定」のハードリミットと表示するが、§6 は同じパラメータを帳簿ごとに DD60%(moonshot)まで可変とする。§6 制約2の非プロファイル化リストに §3 は含まれないため、実態は「§3.2 は aggressive プロファイルの既定値」であり、「ハードリミット(確定)」の表示は読者(=契約当事者たるユーザー)に対して過大表示である。さらに §1 は「全帳簿・全 FM ポッドの合算に適用」と定めるが、プロファイル別の複数仮想帳簿が並走する場合、§3.2 の合算監視が帳簿単位なのか全帳簿横断なのか、moonshot 帳簿の損失が「ファンド」の DD に算入されるのかが規定されていない。

**放置した場合**: moonshot 帳簿の大幅損失時に、サーキットブレーカーの発動要否をエンジンが決定できない(または実装者の解釈で決まる)。「DD25% は確定」という対外的な理解と実際のリスクテイクが乖離する。

**修正案**: §3.2 冒頭に「本節の値は基準プロファイル(aggressive)の値であり、実験プロファイルは §6 の手続で帳簿単位に別値を持つ」と明記。§1 の適用範囲を「帳簿単位で各帳簿のプロファイル値を適用。実弾帳簿は本則のみ」と書き換え、プロファイル横断の総リスク量(例: moonshot 系帳簿への配賦資本上限)を経営管理部予算とは別に定める。

### 懸念6: 実績 SR の月次更新と月次資本再配分は、推定ノイズを制度化している

**何が問題か**: §3.1 は目標リターンを「E9 補正済みの実績 SR で月次更新」、81 §3 は仮想資本を「月次で成績再配分」とする。SR の標準誤差はおよそ √(1/T) であり、1ヶ月(約20営業日)の増分データで動く SR 推定値はほぼノイズである。E9(DSR/PBO)は多重検定の補正であって推定分散の問題を解決しない(E5 が「短期 Sharpe 差で意思決定しない」と定めており、月次再配分はこの原則と緊張関係にある)。また好成績→SR 上方改定→目標リターン上方改定のループは、ドローダウン直前に最も強気になる順循環性を持つ。初期 SR 仮説 1.0 を「保守的」と呼ぶ点も同意しない: コスト控除後 SR 1.0 の持続は較正文書自身が参照する大手マルチストラット水準であり、実績ゼロの新システムの事前分布としては楽観側である。

**放置した場合**: 目標リターンと資本配分が月次で振動し、FM 評価が実力でなく運で決まる。E5 との内部矛盾が監査指摘事項になる。

**修正案**: SR 更新は四半期とし、信頼区間併記+縮小推定(事前分布 SR 0.5 程度への shrinkage)を義務付ける。資本再配分は月次でも「変更幅上限(例: ±25%)」を設け、最低評価期間(例: 3ヶ月)未満の FM は再配分対象外とする。

## 4. CFA Institute 機関投資家向け IPS 標準構成との照合(欠落要素)

本 IPS はガバナンス・リスク目標・報告(月次レビュー)・改訂手続については標準を満たすか上回る。以下が欠落または不十分:

1. **時間軸(Time Horizon)**: 「長期成長」とあるのみで、運用計画のホライズン(何年で何を判断するか)が数値化されていない。懸念1のとおり、DD 較正のホライズン選択に直結するため単なる形式要件ではない
2. **税制(Tax Considerations)**: 記載ゼロ。日本の個人投資家として譲渡益・配当課税(申告分離約20%)、特定口座/NISA の使い分け、高回転取引(§5 で頻度無制限)の税効率、先物・FX(申告分離)と現物の損益通算不可の別は、実弾移行時のネットリターンを直接左右する。E4「全コスト込み」のコスト列挙(手数料・スリッページ・LLM 費・データ費)にも税が含まれていない
3. **通貨ヘッジ方針(Currency Policy)**: 基準通貨 JPY で米国株(Ben/Jim/Peter)と FX(Stan)を扱うにもかかわらず、為替エクスポージャーの扱い(ヘッジするか、しないならリスク予算のどこで計上するか)が無規定。円安局面の米株ポートフォリオでは為替がリターン・リスクの支配項になりうる
4. **流動性要件(Liquidity Requirements)**: 現金下限5%は追証バッファであり、投資家(ユーザー)側の資金引出し・生活資金要件の観点が欠落。デモ中は問題ないが、実弾 IPS には「この資金は何年触らない前提か」が必須
5. **資産クラス分類の定義**: §4.2 の「単一資産クラスのグロス 70%」は分類タクソノミー(日本株と米国株は同一クラスか、指数先物は株式か、金利系の区分)が無定義でゲート実装不能
6. **デリバティブ使用方針**: Stan のマンデートで先物・FX が許可され Kill Switch 条項が「デリバティブ満期」に言及する一方、IPS 本体に許容商品リスト(先物・オプションの可否、OTC の可否)がない。マンデートが事実上商品方針を新設しており、「マンデートは IPS を狭める方向のみ」の原則と緊張する(IPS が無言の商品はデフォルト可なのか不可なのか)
7. **法的・規制制約(Legal/Regulatory)**: 個人口座での FX レバレッジ規制・信用取引規制など、ユニバースに対して実在する規制上限への参照がない
8. **評価・報告頻度の明文化**: NAV 算出頻度・パフォーマンス報告様式は 00-system-design 側に散在。IPS(契約文書)として最低限の参照を置くべき

## 5. §3.1 導出規約の技術的妥当性

**枠組み自体は支持する**。目標リターンを願望でなく E[R] ≈ SR × σ と DD 制約から導出し、「年率100%は DD25% と両立しない」と定量的に退けた点、較正コード・表を公開し限界(GBM の DD 過小評価)を自己申告している点は、同種の個人運用文書では例外的に誠実である。その上で、安全域の取り方に以下の欠陥がある:

1. **ホライズン不整合(最重要・懸念1)**: 較正は「年内」DD、リミットは(定義未記載だが実装上ほぼ確実に)連続測定。当職の追試(同一仮定・4,000パス)で SR1.0/σ20% の連続測定 P(DD>25%) は3年で約33%。「ブリーチ確率 ≤10%」条件は測定定義を書かない限り検証不能な命題であり、連続測定定義の下では現運用値は条件を満たさない
2. **既知バイアスに対する定量的ヘアカットの不在**: 文書は「実運用ではブリーチ確率は表より高いと想定すべき」と書きながら、運用値の選択(σ20%・GBM 確率8.2%)は基準10%との差 1.8pp しか残していない。i.i.d. の t(4) に置換するだけで当職の追試では約9%に上がり、GBM が持たないボラクラスタ(DD はボラ持続下で伸びる)・戦略リターンの負の歪度(ショート・先物・高回転戦略で典型)・レジーム相関(複数ポッドの分散効果がストレス時に消失し、実効 σ が予算を超える — §3 は「相関の変化によらず上限が最終防衛線」と宣言するが、較正はその状況の頻度を測っていない)を加えれば 10% 超過は確実に近い。「保守側に丸める」操作がどこにも入っていない
3. **SR 仮説の性格**: E[R]=SR×σ の SR は実現可能性の仮説であって設計変数ではない。初期値 1.0 を「保守的」とする根拠は文書内に示されておらず、参照実績(較正文書 §3)はむしろ SR 1.0 の持続が世界水準であることを示している。導出規約の出力(目標15〜22%)は「SR 1.0 が実現した場合の整合値」であり、IPS 本文の「目標リターンの現在値は年率15〜22%」という断定調はこの条件付きを落としている
4. **算術平均と幾何平均の混同リスク(軽微)**: 表の E[R] はパス平均(算術)であり、複利ドラッグにより中央値的な体験リターンは μ−σ²/2 相当(σ20% で約2pp)低い。投資家への提示値としてはどちらを意味するか明記すべき
5. **単一シードによる較正(軽微)**: E5 が複数シードの分散報告を義務付ける一方、較正自体は seed 7 単発。主要セルの確率(数%〜)では2万パスのMC誤差は小さいが、moonshot の「DD>60% 確率は数%」級のテール値は感度を報告すべき

結論: 導出規約は**維持すべき**だが、運用値(σ15〜20%・目標15〜22%)は条件1(DD 定義+複数年再較正+ヘアカット)の完了までは**未検証の暫定値**として扱うのが正しい。

## 6. 良い点

- **二層構造(IPS/マンデート)と「狭める方向のみ有効」原則**: GPIF・年金実務の正確な移植であり、スキーマ検証で緩和を拒否する設計は形骸化を防ぐ実効的な仕組み
- **目標リターンの導出規約化**: 「年率100%と DD25% の非両立」を較正で示し、高リスク志向を moonshot プロファイルに隔離して本則を汚染させなかった判断は、ユーザー要望への追従を拒否した実例として高く評価する
- **Kill Switch の3モード化と根拠**: 「凍結が常に最善ではない」(凍結中も市場リスク・満期は残る)という認識、②③を LLM 非経由の決定論コードに限定した点は実務的に正しい
- **レバ型 ETF 禁止の理由記載**: ボラティリティ・ドラッグと「見えないレバレッジ」の2論拠は正確で、「同じ積極性は測れるレバレッジで取る」という代替の提示まで含めて模範的
- **§7.2 コスト実額按分**: 小規模帳簿の不成立を「隠さず情報として扱う」判断は E9 の思想と一貫している
- **改訂フローの自己批判機構**: 機会費用分析・「ルールを曲げた回数」の可視化・懸念ゼロ意見書の不受理は、IPS の生きた運用を担保する優れた設計
